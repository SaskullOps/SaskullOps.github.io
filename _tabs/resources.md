- **Power Automate** - Automatización de procesos en el ecosistema Microsoft/M365
- **Gitea + Watchtower** - Git self-hosted y auto-actualización de contenedores

## 🤖 IA & LLM

- **Ollama** - Runtime local para LLMs (llama3.1, qwen2.5-coder) sin coste de API
