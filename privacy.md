This site and the @s4skull Instagram automation are run by one person (SaskullOps) for personal, non-commercial use.

## What the Instagram automation reads

When you comment on a post by @s4skull, the automation reads the comment text, the comment id and your public username through the Instagram Graph API. It does this only to check whether the comment contains the keyword announced in the post.

## What it does with it

If the keyword matches, it replies to your comment and may send you one private message with the promised link, for example a GitHub repository. It doesn't send marketing, doesn't add you to any list and doesn't message you again unless you reply.

## What is stored

The automation keeps the comment id and a timestamp so the same comment is never answered twice. The site owner also receives a private notification with your public username and the keyword, so a failed reply can be handled by hand. Nothing else is kept.

## Sharing

No data is sold or shared with third parties. Data passes through Meta's platform under Meta's own policies.
